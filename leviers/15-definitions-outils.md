# 15. Des définitions d'outils envoyées à chaque appel

| | |
|---|---|
| Famille | Forme des briques d'IA |
| Gain argent | 10 à 40 % de l'entrée d'un agent |
| Gain latence | Faible |
| Comment prouver | Calcul |
| Données nécessaires | Événements (outils de la requête) |
| État | Détection faite (R13), gain estimé à confirmer |
| Règle | R13 tool_bloat |

## Le signal
Vingt outils décrits longuement à chaque tour d'agent, deux utilisés.

## Comment le détecter
Taille des définitions d'outils vs outils réellement appelés.

## Ce qu'on propose au client
Ne passer que les outils utiles à l'étape ; descriptions courtes ; cache.

## Comment le prouver avant de le recommander
Jetons économisés × prix.
