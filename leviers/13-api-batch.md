## Le signal
Rafales nocturnes ou planifiées, sans utilisateur qui attend.

## Comment le détecter
Répartition horaire, absence de streaming, déclencheur planifié (n8n).

## Ce qu'on propose au client
API batch des fournisseurs (−50 %).

## Comment le prouver avant de le recommander
Calcul sur les prix batch.
